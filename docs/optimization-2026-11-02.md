# 声阅书架、分卷与音色设置优化 2026-11-02

本轮针对两个使用问题做了整体调整：多文件/多分卷的长篇小说不好展示和归类；阅读器里的音色设置与 API 服务默认设置互相干扰。改动位于 `mac-qwen-metal` 工作区，未提交 Git。

## 一、发现的问题

| 问题 | 影响 |
| --- | --- |
| 整书生成时，只要服务默认音色、Seed、采样参数或阅读器里选的 AAC 码率与书的设置不同，就把新设置一起提交，服务端随即**清空整本已生成的音频**且不提示 | 在 QwenTTS App 里换了服务默认音色或只改了码率，再点“生成整本书”，之前几小时的结果就没了 |
| 实时流式与在线整块固定使用服务默认设置（`use_service_settings=1`），整书 AAC 使用书的设置 | 同一本书边听边生成时两种声音；服务默认一变，正在听的流式播放还会被强制停止 |
| 更换生成参数时阅读位置被重置到第 1 块 | 换音色后找不到读到哪里 |
| “第 N 卷”被当成普通章节；追加文件的接口存在但界面没有入口 | 分卷长篇只能分成多本互不相关的书，书架杂乱；几千章的目录是一个平铺长列表 |
| 只在目录里翻章（不播放）不会更新书签 | 重新打开时回到上次播放的位置，而不是正在读的章节 |
| `aac_at` 被 `ffmpeg -encoders` 列出但运行时初始化失败（沙箱/系统服务异常）时，每一段都编码失败 | 整书生成全部失败；已复现 |

## 二、设计：三类设置分开

| 设置 | 范围 | 在哪里改 |
| --- | --- | --- |
| 阅读外观：字号、行距、字体、版心宽度、主题、高亮色、播放时自动滚动 | 当前浏览器 | 声阅 → 设置 → 阅读外观 |
| 本书朗读：音色、模型、Seed、AAC 码率 | 单本书（保存在书的 manifest） | 声阅 → 听书 → “更改”，或 设置 → 本书朗读，或 管理 → 朗读设置 |
| 服务默认音色 | API 调用和新导入的书 | QwenTTS App → “设为服务默认”（声阅中只读显示） |

服务默认变化后，声阅只在“听书”面板里提示“服务默认现在是 X，本书仍用 Y”，并提供“本书改用服务默认”（有已生成音频时需二次确认）。

## 三、改动

**后端（`document_projects.py`、`routers/documents.py`）**

- 新增 `VOLUME_HEADING_RE`（第 N 卷/部/集、卷 N、Volume/Book/Part N）。卷标题紧接章标题时与该章一起朗读；卷标题后有正文时成为以卷名命名的一章。manifest 新增 `volumes`，章节带 `volume_index`；公开数据给出每卷的章节范围。
- `POST /append` 支持 `volume_title`：单文件书第一次追加时，原内容自动成为第一卷（以原文件名命名）；追加文件自带卷标题时保留其卷结构。
- `PUT /api/document-projects/{id}` 可分别更新 `name`、`series`、`volumes[].title`；创建时可带 `series` 与 `voice_label`。
- 新增 `PUT /api/document-projects/{id}/settings`：只比较真正影响声音的字段（模型、参考音频、克隆模式、参考文本、配置的 Seed、采样参数、语言）。会清除已生成音频时返回 409 `reset_required` 与段数，需 `confirm_reset` 才执行；只改码率不重新合成，清掉旧整书文件并提示重新合并。
- 更换参数不再重置阅读位置。
- 书架摘要新增 `series`、`volume_count`、`reading_chapter_title`、`last_read_at`，并去掉 `sources`/`volumes` 以保持轻量。
- `run_aac_encode`：`aac_at` 失败时自动改用内置 `aac` 重试，并在本进程内记住。

**阅读器（`web/novel_reader/`）**

- 整书生成不再提交任何设置；实时流式与在线整块改为使用书的设置（`use_service_settings=0`）；服务默认变化不再停止播放。
- 导入：支持多选与拖入窗口；三种方式——合并为一本（每个文件一卷）/ 分别成书归入同一系列 / 追加到已有书籍；文件按“阅读顺序”排序（识别中文数字与上中下）；自动推断系列名；导入时可选择本书音色（服务默认、预设或音色库）。部分失败时提示已完成几个文件。
- 书架：搜索、排序（最近阅读/最近导入/书名）、同系列折叠分组（折叠状态记住），卡片显示“读到某章”、卷数、字数（万字）。管理面板可搜索，可编辑书名与系列、追加分卷、打开朗读设置。
- 目录：按卷折叠分组（含每卷音频进度）；无分卷且超过 150 章时按 100 章分组；只渲染展开的分组；章节搜索（标题或章号，回车跳转）；跨卷翻章自动展开；章节标题处显示“卷名 · 第 n / N 章”。
- 本书朗读设置对话框：显示改动影响（清除多少段 / 只改码率 / 无需清除），破坏性修改按钮变红并写明“清除音频并保存”。
- 逻辑放入 `reader-model.js`（可在 Node 中测试）：`groupLibrary`、`inferSeriesName`、`sortFilesNaturally`、`buildTocGroups`、`filterChapters`、`bookVoiceSettings`、`voiceDiffers` 等。

**原生 App**

- 工作台按钮改为“设为服务默认”，并说明它只影响 API 与新书。
- 阅读器 App 的文件面板提示可多选分卷文件。

## 五、在 Mac 上的验收

1. `./scripts/verify_all.sh`，重启后台服务并安装新 App。
2. 一次选择 3 个分卷文件导入为一本书，确认目录按卷分组、“第十卷”在最后；再试“分别成书 + 系列”和“追加到已有书籍”。
3. 在 QwenTTS App 中把另一个音色“设为服务默认”，回到声阅：正在播放的不应中断，“听书”面板出现差异提示；点“生成整本书”不应清除已有音频。
4. 在“本书朗读设置”里只改码率 → 已生成段落保留；换音色 → 提示清除段数，确认后阅读位置不变。

## 六、第二轮：按用户流程逐条梳理

完整流程见 [user-flows.md](user-flows.md)。本轮修复的流程断点：

- **已生成的音频不被使用**：▶ 或“起播”总是重新实时合成，即使整本书已经生成。现在先播放保存的 AAC；播到没有音频的段落时，自动以所选方式继续实时朗读。
- **生成期间不能听**：现在可以播放已完成的段落，新完成的段落会自动接上，不会与生成争用 GPU。
- **只能生成整本书**：新增“生成范围”（从当前章到结尾、当前章、当前卷、整本书），按钮显示待生成段数；全部完成后仍会自动合并整书。
- **工作台的预设会隐式改变服务默认**：“应用”、“保存”、“更新”预设都会把它设为服务默认。现在改为：“载入”只影响编辑器，只有“设为服务默认”和菜单栏“服务默认音色”会改变服务默认。菜单对勾、预设列表中的“· 服务默认”标记都反映真实的服务状态；删除服务默认预设时会提示服务已恢复为内置音色。
- 对外接口对话框说明了 API 默认使用的音色，以及重启会中断正在进行的任务。

新增测试：`test_reader_player.cjs` 增加 4 项（优先播放保存的 AAC、保存的音频播完后转为实时朗读、生成期间不实时合成且新段落自动接入、生成范围计算）。原生行为测试可以编译，但沙箱不允许写系统临时目录，未能运行。
