# 用户流程梳理（2026-11-02）

按“用户想做什么 → 从哪里进入 → 怎么操作 → 看到什么结果”逐条整理 Qwen 声阅（阅读器）与 QwenTTS（菜单栏 + 音频工作台）的业务流程。“状态”一列：✅ 本轮已梳理并验证；🔧 本轮发现问题并已修复；⚠️ 已知限制。

## 核心概念：三种设置，各管各的

| 设置 | 作用范围 | 修改入口 | 被谁使用 |
| --- | --- | --- | --- |
| 阅读外观 | 当前浏览器 | 声阅 → Aa 设置 → 阅读外观 | 只影响显示 |
| 本书朗读设置 | 单本书 | 声阅 → 听书 →“更改”；Aa 设置 → 本书朗读；管理 → 朗读设置 | 这本书的实时朗读、在线整块、整书生成 |
| 服务默认音色 | 本机 TTS 服务 | 工作台“设为服务默认”；菜单栏“服务默认音色” | 未指定音色的 API 调用；导入新书时的默认音色 |
| 语音预设 | 已保存的参数组合 | 工作台“语音预设” | 只是模板：载入编辑器、作为新书或本书的音色来源、设为服务默认 |

规则：**修改服务默认不会改动任何已导入的书；修改一本书不会改动服务默认；载入、保存、更新预设不会改动服务默认**（只有被设为服务默认的那个预设，更新后服务会同步使用新参数，界面会明确提示）。

## 一、Qwen 声阅（阅读器）

### 书架与导入

| 用户目标 | 入口 → 操作 | 结果与反馈 | 状态 |
| --- | --- | --- | --- |
| 导入一本书 | 书架“＋”、空状态“选择小说”、或拖入窗口 → 确认书名、可选系列、本书音色、分块大小 → “解析并加入书架” | 自动识别卷、章并打开；提示“N 章，M 卷” | ✅ |
| 导入分成多个文件的长篇 | 多选文件或拖入多个 →“合并为一本书” | 按阅读顺序（识别“第十卷”和上、中、下）每个文件一卷；部分失败时提示完成了几个 | 🔧 新增 |
| 把几本书归成一个系列 | 多选 →“分别成书，归入同一系列”；或 管理 → 编辑 → 填写系列 | 书架折叠为一组，系列名自动推断 | 🔧 新增 |
| 给已有的书追加后续分卷 | 导入时选“追加到已有书籍”；或 管理 →“追加分卷” | 作为新卷接在末尾，已生成的音频保留；若是当前在读的书，原地刷新，不打断播放 | 🔧 新增 |
| 找书 | 书架搜索框；排序（最近阅读、最近导入、书名） | 实时过滤；卡片显示“读到第几章”、卷数、字数、音频进度 | 🔧 新增 |
| 改书名或系列、删除书 | 书架“管理” → 编辑、删除（需二次确认） | 生成中禁止删除，并说明原因 | ✅ |

### 阅读

| 用户目标 | 入口 → 操作 | 结果与反馈 | 状态 |
| --- | --- | --- | --- |
| 继续上次阅读 | 打开书 | 回到书签；在目录中翻章也会更新书签 | 🔧 之前只有播放才记书签 |
| 在几百、几千章中找章节 | 目录 → 按卷折叠；输入标题文字或章号后回车 | 跳到该章；跨卷翻章时自动展开对应的卷 | 🔧 新增 |
| 调整字号、行距、字体、版心宽度、主题 | Aa 设置 → 阅读外观 | 立即生效，只保存在本机浏览器 | 🔧 新增行距、字体、宽度 |
| 手动阅读时不被播放进度带着走 | Aa 设置 → 关闭“播放时自动滚动” | 播放时不再自动滚动 | 🔧 新增 |
| 修改错字 | “编辑正文” → 改完离开文字块即保存 | 该段音频失效并需要重新生成；编辑时不会被定时刷新覆盖 | ✅ |

### 听书

| 用户目标 | 入口 → 操作 | 结果与反馈 | 状态 |
| --- | --- | --- | --- |
| 开始听 | ▶、空格、“听书”→“起播”、点击文字块 | **已生成的段落直接播放保存的 AAC**；播到没有音频的段落时，自动用所选方式（实时流式或高质量整块）继续 | 🔧 之前即使已生成也会重新实时合成 |
| 边生成边听 | 开始整书或范围生成后按 ▶ 或点已生成的段落 | 播放已完成的段落，新完成的段落会自动接上；追上生成进度时提示“生成后点 ▶ 继续” | 🔧 之前生成期间完全不能听 |
| 暂停、继续、停止、上一块、下一块、切章 | 播放条与快捷键（空格、←/→、J/K、[ ]、S） | 状态机保证不会重复起播；停止后保留位置 | ✅ |
| 调整倍速 | 播放条“倍速” | 保存的 AAC 变速不变调；实时流式固定 1×，并显示提示 | ✅ |

### 生成音频

| 用户目标 | 入口 → 操作 | 结果与反馈 | 状态 |
| --- | --- | --- | --- |
| 只生成一部分 | 听书 →“生成范围”：从当前章到结尾（默认）、当前章、当前卷、整本书 → 开始生成 | 按钮显示“待生成 N 段”；已生成的跳过；全书都完成后自动合并 M4A | 🔧 之前只能生成整本 |
| 查看进度、停止、继续 | 进度条与“查看详情”；“停止当前生成” | 当前段保存后暂停；之后可继续 | ✅ |
| 下载整书 | 全部完成后点“下载整书 M4A” | — | ✅ |

### 音色

| 用户目标 | 入口 → 操作 | 结果与反馈 | 状态 |
| --- | --- | --- | --- |
| 为这本书换音色、模型或 Seed | 听书 →“更改” | 先显示影响：要清除多少段，或“无需清除”；破坏性操作的按钮变红；阅读位置保留 | 🔧 新增 |
| 只改码率 | 同上，只改“整书 AAC 码率” | 已生成的段落保留，合并时按新码率编码 | 🔧 之前会清空全部音频 |
| 服务默认变了，想让这本书跟着改 | 听书面板中的差异提示 →“本书改用服务默认” | 有音频时需要二次确认 | 🔧 新增 |
| 服务默认变了，不想影响正在听的书 | 什么都不用做 | 播放不中断，音色不变 | 🔧 之前会强制停止播放，并在下次生成时清空音频 |

## 二、QwenTTS（菜单栏与音频工作台）

| 用户目标 | 入口 → 操作 | 结果与反馈 | 状态 |
| --- | --- | --- | --- |
| 试听一种音色或参数 | 工作台：选参考音色或“载入”预设 → 输入文本 →“生成语音” | 流式试听；不会改变服务默认 | 🔧 之前“应用”预设会顺带改掉服务默认 |
| 保存或更新预设 | 工作台 →“保存新预设”或“更新” | 提示“未改变服务默认”；若该预设正是服务默认，提示“API 与新书立即使用新参数” | 🔧 之前保存即设为服务默认 |
| 设定 API 的默认音色 | 工作台“设为服务默认”（编辑器未改动时直接关联所选预设）；或菜单栏“服务默认音色”→ 选择预设 | 菜单对勾显示真正的服务默认；按钮显示“已是服务默认”；说明它只影响 API 与新书 | 🔧 之前菜单对勾取的是编辑器选择 |
| 删除预设 | 工作台“删除选中预设” | 若它是服务默认，提示“服务已恢复为内置默认音色” | 🔧 之前没有提示 |
| 管理参考音频 | 导入音频或视频、录音、录制系统声音 → 裁剪 →“管理参考音频” | 删除时若仍被书籍或任务使用，会给出提示 | ✅ |
| 开启局域网 API、设置密码 | “对外接口” → 保存并重启 | 说明 API 默认用哪个音色，以及重启会中断正在进行的任务 | 🔧 补充说明 |
| 启动或停止服务、强制停止 | 菜单栏 / 工作台顶部状态胶囊 | 启动中禁用重复操作 | ✅ |
| 为这台 Mac 选择性能策略 | 工作台“测试性能” | 自动用于阅读器与整书任务 | ✅ |

## 三、已知限制

- ⚠️ 实时流式固定 1× 倍速（变速需要时间拉伸，尚未实现）。
- ⚠️ 单个文字块没有“重新生成本段”按钮；需要通过编辑正文或重新生成范围来实现。
- ⚠️ 声阅中的音色列表来自预设与音色库；新建或调整音色仍需要在工作台中完成。
- ⚠️ 语音转文字工作台本轮只做了入口检查，未逐项重走。
